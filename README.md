# Mirashya Airbnb Clone

Desktop-only React/Vite recreation of the supplied Airbnb listing reference. Built independently from screenshots and behavioral observation; no reference source code is included.

## Run

```bash
npm install
npm run dev
npm run build
```

## Required flows

- Listing Page
- Photo Tour via Show all photos / gallery interaction
- Lightbox with mouse arrows, ArrowLeft/ArrowRight and Escape
- Amenities modal
- Save state with wishlist toast
- Sticky navigation and booking card

## Submission contents

- `src/` application source
- `public/images/` local listing imagery
- `docs/architecture.svg` production-scale architecture diagram
- `.ai/agents/` and `.ai/skills/` AI workflow configs
- `PROMPTS.md` prompt sequence
